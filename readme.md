# Comandos
W, A, S, D - controla a posição da câmera
Mouse - controla para onde a câmera está olhando
C - Move a posição da câmera para baixo
Espaço - Move a posição da câmera para cima
Esq - Fecha o programa
L - Altera entre luz rodando automaticamente pelo tabuleiro e luz de controle manual

## Apenas em modo controle de luz manual
Setas do teclado - Move a luz (frente, tras, esquerda e direita)
J - Move a luz para cima
M - Move a luz para baixo
